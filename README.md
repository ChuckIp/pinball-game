# Ask Alexa Pinball

Pinball Space Adventure game bought then customised for Ask Alexa.

## Development

- Original source code including documentation at: `/code-original`
- Custom code at: `/code-custom`
- As we're customising third party code, please disable all linting and formatting settings.
- Edit files directly in `/code-custom`
- To run locally, open `/code-custom/game/index.html` in your browser.

## Deployment

- Upload as file activity and set `index.html` as main file.
