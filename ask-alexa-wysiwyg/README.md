# Ask Alexa WYSIWYG

This html code is used to style the iframe and the course the game will sit on

## Development

- Style tags are automatically stripped in the wysiwyg so styling must be done in the script tags
- Make sure your javascript functions are scoped within a function, in order to not overwrite other JS functions on the page

## Deployment

- Copy and paste the html script code into the wysiwyg located on the same page as the course
